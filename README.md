# Hospital Operations & Patient Experience Dashboard

**An Interactive Healthcare Analytics Dashboard Built with Microsoft Power BI**

## Project Overview

The **Hospital Operations & Patient Experience Dashboard** is an interactive business intelligence project developed using Microsoft Power BI. It transforms hospital data into meaningful insights to help understand patient flow, hospital performance, waiting times, admission patterns, and patient satisfaction.

The dashboard provides an analytical view of hospital operations through interactive visualizations, key performance indicators (KPIs), patient demographics, and time-based analysis.

The primary objective of this project is to demonstrate how data analytics and visualization can support better operational monitoring and data-driven decision-making in the healthcare sector.

## Dashboard Pages

### 1. Monthly View

Provides an overview of hospital performance and patient activity.

Key insights include:
- Total number of patients
- Average patient waiting time
- Patient satisfaction score
- Total patients referred
- Patient distribution by age group
- Patient distribution by gender
- Patient admission status
- Department referral analysis
- Patient waiting-time analysis
- Daily and monthly patient trends

### 2. Patient Details

Provides a detailed patient-level view with information such as:

- Patient ID
- Patient name
- Gender
- Age
- Admission date
- Patient race
- Waiting time
- Department referral
- Admission status

## DAX Measures

The project includes measures for important hospital performance indicators, including:

- `No_of_patients`
- `Avg_Wait_time`
- `Satisfaction_score`
- `Patients_referred`

These measures support KPI reporting and interactive analysis.

## Business Questions Addressed

This dashboard helps explore questions such as:

1. How many patients are visiting the hospital?
2. What is the average patient waiting time?
3. How does patient satisfaction vary over time?
4. Which age groups account for the highest patient volume?
5. What is the distribution of patients by gender?
6. What are the patterns in hospital admissions?
7. Which departments receive the most patient referrals?
8. How does patient volume change across different days and months?
9. What are the patterns in patient waiting times?

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded Power BI file.
4. Explore the dashboard pages.
5. Use the available filters and slicers to interact with the visualizations.

*Note: Data source configuration or refresh permissions may need to be updated depending on your environment.*
